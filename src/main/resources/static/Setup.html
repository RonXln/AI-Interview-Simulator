⚠️重要说明（请务必阅读）
为还原真实面试，本模拟服务在面试期间会有以下行为：
  • 整场面试期间，麦克风将持续保持开启状态，您的语音会实时传输给后端用于识别和应答。
  • 会议界面中的「静音 / Mute」按钮仅为视觉演示，点击后 UI 会变化（如同真实 Zoom），但不会真正关闭麦克风。
  • 面试结束后，麦克风会立即被释放，不再录音。
  • 音频仅用于本次面试的实时问答，不会被存储或上传到第三方。
  • 隐私保证：本页面收集的任何个人信息（包括个人文书 Personal Statement、活动列表 Activity List、CV 等），仅在本次面试会话内存中临时用于生成面试问题，面试结束后将立即从服务器内存中删除，不做任何形式的持久化存储，不会上传至任何第三方，也不会用于训练任何模型。
